# Personal-Brand
Создание Личного Бренда

## Идеи
> **Digital Expert / Цифровой Эксперт**
>
> Это добавка из предложенного Гугл AI промпта. Расположить под фамилией в текстовой части Личного бренда либо где-либо в составе Графической части.

> **Экслибрис**
> 
> Сделать в стилистике позабытого ныне Экслибриса, только без излишней пышности и креативности, не выбиваясь из общей концепции стилистики Личного бренда.
