# Personal-Brand
Создание Личного Бренда

## Идеи
> **Digital Expert / Цифровой Эксперт**
>
> Это добавка из предложенного Гугл AI промпта. Расположить под фамилией в текстовой части Личного бренда либо где-либо в составе Графической части.

> **Экслибрис**
> 
> Графическую часть сделать в стилистике позабытого ныне Экслибриса, только без излишней пышности и креативности, не выбиваясь из общей концепции стилистики Личного бренда.
> 
> [Экслибрис / Википедия](https://ru.wikipedia.org/wiki/%D0%AD%D0%BA%D1%81%D0%BB%D0%B8%D0%B1%D1%80%D0%B8%D1%81)

> **Маскот**
>
> Также, в дополнение к 2-м базовым элементам бренда: текстовуой части и графическому знаку, сделать Маскот, возможно на основе фотки "Я наблюдаю за тобой", только в очках.
